# 日期查询工具

一个实用的日期查询工具，支持多种日期相关功能，帮助您轻松查询日期信息、分析日期分布和查找农历公历重合年份。

## 🌟 功能特色

### 1. 具体日期查询
- 查询任意日期是星期几
- 判断是否为节假日或调休工作日
- 显示详细日期信息

### 2. 日期可能性分析
- 分析某月某日在多年中落在周末的概率
- 查看具体年份分布情况
- 统计工作日和周末比例

### 3. 农历公历重合查找
- 找出农历生日对应公历的年份
- 支持自定义起始年份
- 快速找到日期重合的特殊年份

## 🚀 快速开始

### 第一步：安装Python
如果您还没有安装Python，请先下载安装：
- 访问 [Python官网](https://www.python.org/downloads/)
- 下载最新版本（推荐 Python 3.8+）
- 安装时记得勾选"Add Python to PATH"

### 第二步：下载工具
1. 将代码文件保存为 `date_tool.py`
2. 或者直接克隆这个项目（如果有的话）

### 第三步：安装依赖
打开命令行（终端），输入以下命令：
```bash
pip install requests tqdm colorama lunardate
```

### 第四步：运行工具
在命令行中运行：
```bash
python date_tool.py
```

## 📖 使用指南

运行程序后，您将看到彩色菜单界面：

```
==========================================================
日期查询工具套件
==========================================================
请选择功能：
1、查询具体日期[查询某日是星期几，是否为节假日]

3、农历公历重叠年份查找[找出农历与公历同日的年份]
0、退出程序

```

### 功能1：查询具体日期
**使用场景**：想知道某天是不是节假日？星期几？

**支持输入格式**：
- 4月5日、4-5、4.5、4/5
- 四月五日、0405、405

**示例**：
```
请输入查询年份（回车=当前2024）: 2024
请输入月日（如：4月5日）: 5月1日

==================================================
具体日期查询结果
==================================================
日期：2024年05月01日
星期：周三
状态：节假日
说明：劳动节
节假日：劳动节
==================================================
```

### 功能2：分析日期可能性
**使用场景**：了解生日在多年中落在周末的概率

**示例**：
```
请输入要分析的月日（如：4月5日）: 10月1日
请输入年份范围（如：2020-2030，默认即此）: 2020-2030

分析结果：
周末概率：36.4%
工作日概率：63.6%
```

### 功能3：农历公历重合查找
**使用场景**：找农历生日与公历生日同一日的年份

**示例**：
```
请输入农历月日（如：1月1日）: 1月1日
请输入公历月日（如：1月1日）: 2月10日

匹配年份：2024, 2043, 2062 等6年
```

## ❓ 常见问题

### Q: 程序运行时提示"模块未找到"
A: 请确保已安装所有依赖库：
```bash
pip install requests tqdm colorama lunardate
```

### Q: 节假日数据获取失败
A: 检查网络连接，程序会使用缓存数据，但第一次需要联网下载

### Q: 如何退出程序？
A: 在任何输入界面输入 `q`、`quit` 或 `exit` 即可退出

### Q: 支持哪些日期格式？
A: 支持多种格式：
- 数字格式：4月5日、4-5、4.5、4/5、0405
- 中文格式：四月五日、正月初一

## 💡 使用技巧

- 快速查询：直接按回车使用默认年份
- 颜色提示：绿色=节假日，黄色=周末，蓝色=调休
- 批量分析：功能2可以分析多年数据，适合活动策划
- 农历查询：功能3适合找农历生日与公历生日同一天的年份
