# 日期查询工具

一个实用的日期查询工具，支持多种日期相关功能，帮助您轻松查询日期信息、分析日期分布。

## 🌟 功能特色

### 1. 具体日期查询
- 查询任意日期是星期几
- 判断是否为节假日或调休工作日（支持多种在线数据源自动切换）
- 显示详细日期信息

### 2. 日期可能性分析
- 分析某月某日在多年中落在周末的概率
- 查看具体年份分布情况
- 统计工作日和周末比例

## 🚀 快速开始

### 第一步：环境准备
确保您的电脑已安装 Python 3.8 或以上版本。

### 第二步：安装依赖
打开命令行（终端），在项目目录下运行：
```bash
pip install -r requirements.txt
```
*主要依赖：`requests`, `tqdm`, `colorama`, `jsonschema`*

### 第三步：运行工具
在命令行中运行：
```bash
python Date_Tool.py
```

## 📖 使用指南

运行程序后，您将看到彩色菜单界面：

```
======================================================================
               🗓️  日期查询工具套件
======================================================================
1) 查询具体日期
2) 分析日期可能性
3) 清理本地缓存
0) 退出
======================================================================
```

### 功能1：查询具体日期
**使用场景**：想知道某天是不是节假日？星期几？需不需要调休？

**操作说明**：
1. 输入年份（直接回车默认为当前年份）。
2. 输入日期（支持 `4月5日`、`4-5`、`4.5`、`YYYY-MM-DD` 等格式）。
3. 查看结果（包含星期、节假日/工作日/调休状态）。
4. **按任意键**继续查询下一个日期，或按 **'q'** 返回主菜单。

**数据源说明**：
工具会自动尝试节假日 API 源，并支持本地缓存，确保查询快速且稳定。
缓存文件会在首行记录下载时间，默认超过 7 天自动过期重新拉取；可使用 `python Date_Tool.py --refresh` 强制刷新缓存。

### 功能2：分析日期可能性
**使用场景**：了解生日、纪念日等固定日期在未来几年中落在周末/工作日的概率。

**示例**：
```
请输入要分析的月日（如：4月5日）: 10月1日
请输入年份范围（如：2020-2030，默认即此）: 2020-2030

分析结果：
周末概率：36.4%
工作日概率：63.6%
```

## ❓ 常见问题

### Q: 节假日数据获取失败怎么办？
A: 程序内置了多个 API 源自动切换机制。如果所有在线源都不可用，程序会自动降级使用基础算法（仅判断周末），确保基本功能可用。同时，成功获取的数据会被缓存到本地 `holidays_YYYY.json` 文件中，下次无需联网。

### Q: 如何退出程序？
A: 在主菜单输入 `0`，或在查询过程中按 `q` 即可退出。

### Q: Windows下运行乱码？
A: 程序使用了 `colorama` 库自动处理终端颜色，请确保在 CMD 或 PowerShell 中运行。
